# 📊 economicnewrussiabot

Автопостер новостей экономики РФ для Telegram-канала.
Постит **не по списку лент, а по индексу цитируемости**: широкий захват →
кластеризация по сюжетам → подсчёт независимых источников → публикуются только
сюжеты, перешагнувшие порог.

Только стандартная библиотека Python. Только бесплатные источники.

## Источники (бесплатные, без ключей)

| Источник | Что даёт |
|----------|----------|
| **Google News RSS** | Уже сгруппировано по сюжетам, источник зашит в заголовок — основной поставщик цитируемости |
| **GDELT DOC 2.0** | Широкий мировой захват (сотни тысяч источников), русскоязычные статьи об экономике РФ |
| **Telegram-каналы** | Публичная веб-витрина `t.me/s/<channel>` — подтверждение темы между каналами |

## Как работает индекс цитируемости

1. Заголовки нормализуются (стемминг, стоп-слова) → множество токенов.
2. Жадная кластеризация по сходству (Jaccard) объединяет сообщения об одном событии.
3. **Индекс цитируемости = число независимых источников в кластере.**
4. Публикуются только кластеры с `citation >= citation_threshold`.
5. Антидубль через SQLite: похожий сюжет (Jaccard ≥ 0.45) повторно не постится.

## Настройка

1. Получить токен у [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Создать канал, добавить бота **администратором** (с правом публикации).
3. Вписать в `config.json`:
   - `bot_token` — токен бота;
   - `channel_id` — `@username` канала (или числовой ID).
4. При желании подкрутить:
   - `citation_threshold` — порог публикации (по умолчанию 4 источника);
   - `max_posts_per_run` — максимум постов за проход;
   - `telegram_channels`, `google_news_queries`, `keywords`.

## Запуск

```bash
python3 bot.py --dry-run   # тест: всё собирает и печатает посты, НО не отправляет
python3 bot.py             # один проход: собрать и опубликовать
python3 bot.py --loop      # бесконечный цикл с паузой interval_hours
```

## Автозапуск по расписанию (macOS / cron)

```bash
# каждые 2 часа
crontab -e
0 */2 * * * cd "/Users/maksim/Desktop/YOUTUBE 1/economic_news_bot" && /usr/bin/python3 bot.py >> run.log 2>&1
```

или просто оставить запущенным `python3 bot.py --loop`.
